# Hablemos

A personal Spanish trainer for moving to Mexico. The goal is to be conversational in 6 months and fluent in 12.

- **Website (GitHub Pages):** https://ayerokun-cmd.github.io/hablemos/
- **claude.ai version:** https://claude.ai/artifact/C1B1frUVgKhjZvwdHAVczD

## What's inside

- **Lección:** one guided 90-minute lesson a day in six timed steps. It saves as you go, so you can stop and continue later the same day.
- **Tarjetas:** spaced-repetition flashcards of Mexican Spanish phrases, verbs, connector words and expressions, with audio.
- **Leer:** readings at your level written by Claude, with tap-to-translate words and comprehension questions.
- **Conversar:** an AI tutor ("Lupita") who acts out real situations in Mexico and corrects your Spanish.
- **Ruta:** a 12-month roadmap in five phases, with goals to tick off.

## The two versions

| | GitHub Pages site | claude.ai version |
|---|---|---|
| AI tutor and new readings | Your own Anthropic API key (Ruta → Ajustes) | Included with claude.ai |
| Voice and mic | The browser's built-in speech | claude.ai voice and dictation |
| Progress | Saved in that browser only | Saved to your claude.ai account |

The API key is stored only in your browser and sent only to `api.anthropic.com`. It never goes into this repo.

## Files

- `src/app.html`: the app source. This is what gets published to claude.ai.
- `index.html`: the GitHub Pages site, generated by `./build.sh`. Don't edit it by hand.
- `manifest.webmanifest`, `icons/`: home-screen app name and icon.

## Updating

Edit `src/app.html`, run `./build.sh`, then commit both files.
